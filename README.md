# Bihangesh Guha — Portfolio

Personal portfolio website of Bihangesh Guha, a Mathematics & Computing
student at IMA Bhubaneswar, working on cryptography, number theory and
quantitative finance.

🔗 **Live site:** https://sky-wth.github.io/portfolio/

## Built with
- HTML, CSS and vanilla JavaScript
- Canvas particle background
- Web3Forms for the contact form
- Hosted on GitHub Pages

## Run locally
Download the files and open `index.html` in your browser.
