# Bihangesh Guha — Portfolio

> Personal portfolio website of **Bihangesh Guha**, a Mathematics & Computing student at the Institute of Mathematics and Applications, Bhubaneswar.

## 🌐 Live Website

**[https://sky-wth.github.io/portfolio/](https://sky-wth.github.io/portfolio/)**

## 🧑‍💻 About

This is a single-page portfolio website showcasing my academic background, technical skills, projects, work experience, independent studies, and contact information. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

## ✨ Features

- **Interactive Particle Background** — Canvas-based particle system with mouse interaction
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices
- **Smooth Scroll Animations** — Intersection Observer-powered reveal effects
- **Contact Form** — Integrated with [Web3Forms](https://web3forms.com/) for direct messaging
- **SEO Optimized** — Structured data (JSON-LD), Open Graph tags, sitemap, and robots.txt

## 🛠️ Tech Stack

| Layer     | Technology       |
|-----------|------------------|
| Markup    | HTML5            |
| Styling   | CSS3 (Custom Properties, Grid, Flexbox) |
| Scripts   | Vanilla JavaScript (ES6+) |
| Fonts     | Inter, JetBrains Mono (Google Fonts) |
| Forms     | Web3Forms API    |
| Hosting   | GitHub Pages     |
